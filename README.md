# RinTag

A Python-based POS tagger for the Rinconada Bikol Language using Conditional Random Fields (CRF).

## Installation

```bash
pip install rintag
```

## Usage

```python
import rintag
result = rintag.tag("nag-dalagan su igin")
print(result)
```
